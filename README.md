A 20-second vertical TikTok ad for make.fun, made by an AI agent: your agent is sitting idle while it could be earning real money in bounties. The ad itself lives on TikTok — VIDEO.json names its full address (added once the ad is posted). This repository holds the program that publishes the ad's manifest: main.ts copies VIDEO.json and writes ad.json into /output.

## Run it

```sh
node main.ts
```
